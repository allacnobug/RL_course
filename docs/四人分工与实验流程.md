# 四人分工与实验流程

本文档用于组内协作。目标是让 4 位同学可以按照固定步骤完成实验、保存结果、整理报告和 PPT。

## 0. 全组统一约定

### 0.1 项目目录

所有命令都在项目根目录运行：

```bash
cd /Users/yujing/Study/RL
```

### 0.2 Conda 环境

第一次运行：

```bash
conda env create -f environment.yml
conda activate rl-course
```

之后每次运行：

```bash
conda activate rl-course
```

如果环境已经存在但依赖更新了：

```bash
conda env update -f environment.yml --prune
conda activate rl-course
```

### 0.3 输出目录

主要输出都在：

```text
outputs/processed/      数据清洗和事件构造结果
outputs/features/       DQN 特征文件
outputs/tables/         baseline 和模型评估表格
outputs/logs/           训练日志
outputs/checkpoints/    模型 checkpoint
outputs/figures/        训练曲线和对比图
```

### 0.4 Git/文件协作建议

每个人只负责自己的部分，不要随意改别人已经跑好的输出。

建议每次实验记录：

```text
负责人
运行命令
开始时间
结束时间
输出文件
关键结果
是否可放入报告
```

## 1. 总体实验流程

完整流程如下：

```text
1. 数据预处理
2. 构造推荐事件
3. 构造 DQN 特征
4. 跑规则 baseline
5. 训练 DQN / Double DQN / Dueling DQN
6. 评估 checkpoint
7. 画训练曲线和对比图
8. 整理报告和 PPT
```

对应代码：

```text
src/preprocess.py
src/build_events.py
src/features.py
src/baselines.py
src/env.py
src/models.py
src/train.py
src/evaluate.py
src/plot_curves.py
```

## 2. 成员 A：数据与特征负责人

### 2.1 负责内容

成员 A 负责把原始数据处理成模型可用的数据。

主要任务：

```text
1. 跑通数据预处理。
2. 跑通推荐事件构造。
3. 跑通 DQN 特征构造。
4. 检查数据规模和缺失情况。
5. 整理报告中的数据集和预处理部分。
```

### 2.2 运行步骤

第一步：数据预处理。

```bash
python src/preprocess.py \
  --data_dir data \
  --output_dir outputs/processed
```

检查输出：

```text
outputs/processed/project.csv
outputs/processed/entry.csv
outputs/processed/worker.csv
outputs/processed/industry_map.json
outputs/processed/stats.json
```

第二步：构造推荐事件。

```bash
python src/build_events.py \
  --processed_dir outputs/processed \
  --output_dir outputs/processed \
  --candidate_size 20 \
  --train_ratio 0.70 \
  --valid_ratio 0.15 \
  --seed 42
```

检查输出：

```text
outputs/processed/events_train.csv
outputs/processed/events_valid.csv
outputs/processed/events_test.csv
outputs/processed/events_stats.json
```

第三步：构造特征。

```bash
python src/features.py \
  --processed_dir outputs/processed \
  --output_dir outputs/features
```

检查输出：

```text
outputs/features/train_features.npz
outputs/features/valid_features.npz
outputs/features/test_features.npz
outputs/features/feature_names.json
outputs/features/features_stats.json
```

### 2.3 需要记录的结果

从这些文件中整理数据统计：

```text
outputs/processed/stats.json
outputs/processed/events_stats.json
outputs/features/features_stats.json
```

需要记录：

```text
project 数量
entry 数量
worker 数量
train / valid / test event 数量
candidate_size
feature_dim
skipped_insufficient_negatives 数量
worker_quality 缺失数量
withdrawn entry 数量
winner / finalist 数量
```

### 2.4 报告负责部分

成员 A 负责报告中的：

```text
数据集说明
数据清洗方法
时间切分方法
候选集构造方法
特征构造方法
避免未来信息泄漏说明
```

## 3. 成员 B：模型与训练负责人

### 3.1 负责内容

成员 B 负责模型结构和训练主实验。

主要任务：

```text
1. 检查 env.py、models.py、train.py 是否能跑。
2. 训练 worker 目标的三个模型。
3. 训练 requester 目标的三个模型。
4. 保存训练日志和 checkpoint。
5. 整理训练参数表。
```

### 3.2 训练前 smoke test

先确认环境和模型能跑：

```bash
python src/env.py \
  --feature_path outputs/features/train_features.npz \
  --reward_type worker \
  --episode_length 5 \
  --steps 8 \
  --seed 42
```

测试模型结构：

```bash
python src/models.py \
  --model dqn \
  --feature_path outputs/features/train_features.npz \
  --candidate_size 20 \
  --batch_size 4
```

快速训练测试：

```bash
python src/train.py \
  --features_dir outputs/features \
  --output_dir outputs \
  --model dqn \
  --reward_type worker \
  --episodes 2 \
  --episode_length 30 \
  --batch_size 8 \
  --buffer_size 200 \
  --min_buffer_size 10 \
  --eval_interval 1 \
  --eval_max_events 500 \
  --device cpu \
  --run_name smoke_dqn_worker
```

## 4. 成员 C：评估、baseline 与画图负责人

### 4.1 负责内容

成员 C 负责实验结果产出。

主要任务：

```text

2. 评估训练好的模型。
3. 画训练曲线。
4. 画 baseline vs DQN 对比图。
5. 整理实验结果表格。
```

### 4.2 跑 baseline

测试集 baseline：

```bash
python src/baselines.py \
  --features_dir outputs/features \
  --output_dir outputs/tables \
  --split test \
  --seed 42
```

如果需要 train / valid / test 都评估：

```bash
python src/baselines.py \
  --features_dir outputs/features \
  --output_dir outputs/tables \
  --split all \
  --seed 42
```

检查输出：

```text
outputs/tables/baseline_results_test.csv
outputs/tables/baseline_results_test.json
```

### 4.3 评估 DQN checkpoint

成员 B 训练完成后运行：

```bash
python src/evaluate.py \
  --features_dir outputs/features \
  --checkpoint_dir outputs/checkpoints \
  --output_dir outputs/tables \
  --split test \
  --device cpu
```

检查输出：

```text
outputs/tables/eval_results_test.csv
outputs/tables/eval_results_test.json
```

### 4.4 画图

  --eval_csv outputs/tables/eval_results_test.csv \
  --output_dir outputs/figures

## 7. 推荐执行顺序

最稳妥的顺序：

```text
1. A 先跑 preprocess/build_events/features。
2. C 跑 baseline。
3. B 跑 smoke test。
4. B 跑 6 个正式模型。
5. C 跑 evaluate。
6. C 跑 plot_curves。
7. D 整合报告和 PPT。
8. 全组检查结果和讲稿。
```

如果训练时间不够：

```text
1. 先保证 dqn_worker 和 dqn_requester 有结果。
2. 再补 double_dqn_worker 和 double_dqn_requester。
3. 最后补 dueling_dqn_worker 和 dueling_dqn_requester。
```
